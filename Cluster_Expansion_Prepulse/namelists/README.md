The namelists in this folder can be used as input files for Smilei, to run 2D simulations. Namely, prepulse_namelist.py is my most up-to-date, useful version for investigating the expansion of a single cluster, in a 1umx1um box, under the Gemini North laser pre-pulse. It starts the simulation from 1ps before the main pulse, running until 2ps after. You can use it to measure density evolution of the cluster under the pre-pulse.
