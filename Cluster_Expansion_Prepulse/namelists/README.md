The namelists in this folder can be used as input files for Smilei, to run 2D simulations. Namely, prepulse_namelist.py is my most up-to-date, useful version for investigating the expansion of a single cluster, in a 1umx1um box, under the Gemini North laser pre-pulse. It starts the simulation from 1ps before the main pulse, running until 2ps after. You can use it to measure density evolution of the cluster under the pre-pulse. It can also be shortened from 3ps total to <1ps total, since ionisation of the cluster only appears 0.2ps ahead of the main pulse, so you can choose to start the simulation at -0.5ps, for example, and run it until 0.2ps after the main pulse. This allows for finer diagnostics during the 700fs of interest, with less memory required.

'prepulse_large_box.py' is similar to 'prepulse_namelist.py', but it is shorter (only 1ps total starting 0.5ps before the main pulse) and with a lower resolution (768 cells-per-wavelength compared to 1024 cells-per-wavelength), to allow use of a 4umx4um box without too much memory required.

'prepulse_plasma.py' includes background electrons and ions to form a neutral background plasma. The aim of this namelist is to investigate the effect of Debye shielding on cluster expansion under the pre-pulse, but the result seems strange. Debye shielding seems to minimally effect the expansion and the background plasma seems to almost entirely get dragged into the centre of the simulation box at the beginning of the simulation. This area needs further exploration.
